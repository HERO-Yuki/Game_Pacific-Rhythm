# Pacific Rhythm — リリース前チェック項目

> 最終審査・公開・Wavedash 提出の前に眺める用の一覧。不要な行は捨て、プロジェクトに合わせて追記してください。  
> **補足:** リポジトリの `.gitignore` で `docs/` 全体が無視されている場合、このファイルを共有したいときは `.gitignore` に `!docs/checklist.md` 等の例外を追加する。

## ビルド・品質

- [ ] `npm run build` がエラーなく完走する（`tsc --noEmit` 含む）
- [ ] `npm run preview` で `dist` がブラウザで動作する
- [ ] コンソールに想定外の大量ログ・未処理 reject が出ていない
- [ ] 本番で不要な `console.log` を削る or 削る方針が決まっている

---

## 難易度・ゲームループ

- [ ] **EASY** … 9 ウェーブで GAME CLEAR まで到達できる
- [ ] **NORMAL** … 15 ウェーブで GAME CLEAR まで到達できる
- [ ] **ENDLESS** … クリアなしでウェーブが進行し、ゲームオーバーで終了する
- [ ] リズム窓（±200 ms）と PERFECT/GOOD の体感が難易度間で意図どおり
- [ ] オーバーヒート・メルトダウン条件が分かる／説明不要で致命的と分かる
- [ ] **PERFECT コンボ** … 連続 PERFECT で火力が上がり、GOOD / MISS / 被弾で途切れる体感が意図どおり
- [ ] **撃破直後** … 800ms の止まり → フラッシュ・パーティクル・`KAIJU DESTROYED` / `PERFECT BONUS` のあと、次ウェーブ or クリアへ違和感なくつながる（裏でリゾルブ拍が続かない）
- [ ] **スコア** … ウェーブ撃破で +1、PERFECT 数に応じたボーナスが右上の表示と矛盾しない
- [ ] `src/config/combatJuice.ts` の定数（フリーズ ms・コンボ 1 段あたり倍率）を触ったあと、実プレイで確認

---

## コンボ・ジュース系（手動回帰）

- [ ] プログラムで **2 CHAIN!** 以上がヒートゲージ付近に出る
- [ ] オーバーヒートで行動が消えたステップで **ERROR**・枠点滅・黒煙・ブザーが出る
- [ ] **EASY / NORMAL クリア** … `GAME CLEAR` 大演出とタイトルへ戻るまで音・画面が破綻しない
- [ ] **ENDLESS ゲームオーバー** … `FINAL SCORE` 大型表示と RETRY / タイトル導線
