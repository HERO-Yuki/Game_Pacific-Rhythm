# 動作チェック — 初回 READY / `GamePhase.INTRO_READY`

> `MainScene` の初回ウェーブ前オーバーレイ（「READY」）と、フェーズ `INTRO_READY` 導入まわりの**手動確認用**リスト。  
> リグレッションのたびにここから抜粋して使ってよい。

---

## 初回 READY（ウェーブ 1 前）

- [ ] タイトルから任意難易度で **ENGAGE** し、`MainScene` に入れる
- [ ] 画面中央に **「READY」** が表示される（フェードイン＋スケールの演出）
- [ ] **READY 表示中**に次が起きてい**ない**こと
  - [ ] 怪獣側スロットが読み取りフェーズとして順に開示されない
  - [ ] リズム用カーソルが怪獣スロットをビートに合わせて進まない
  - [ ] プレイヤー **PROGRAM** フェーズに入らない（ボタンが本番のプログラム用に動き出さない）
  - [ ] 画面上部のフェーズ表示が **READING / PROGRAM** に切り替わらない（READY 専用の状態のまま）
- [ ] READY が消えた**直後**から、ウェーブ 1 の **READING（怪獣シーケンス）** が拍どおりに始まる
- [ ] そのあとの **PROGRAM → RESOLUTION** まで 1 ターンが通る

---

## 難易度・テンポ

- [ ] **EASY / NORMAL / ENDLESS** それぞれで初回 READY の長さが破綻しない（`rhythmMs` に応じた 2 拍ホールド＋消去アニメ）
- [ ] ENDLESS でウェーブ 1 の BPM が意図どおりのうえで、上記「READY 中は進まない」が成り立つ

---

## 2 ウェーブ目以降（リグレッション）

- [ ] ウェーブ 1 撃破後、**ウェーブ 2** のリズムが通常どおり開始する（不要な READY の繰り返しがない）
- [ ] **BOSS / GIGA** ウェーブで WARNING / EMERGENCY オーバーレイが出る場合、その表示中〜解除後もリズムが**意図したタイミング**で始まる

---

## シーン・ビルド

- [ ] `npm run build` が通る（CI またはローカル）
- [ ] `npm run dev` でホットリロード後も、**初回のみ** READY 挙動が変わらない

---

## 画面まわり（任意）

- [ ] READY 表示中にブラウザウィンドウをリサイズしてもクラッシュしない・文字が極端にはみ出さない
- [ ] READY 中に初回クリックで **オーディオアンロック** しても、リズム進行が先走りしない（上記「READY 中は進まない」と同義で再確認可）

---

## Material Icons（Canvas）

- [ ] スロット・アクションボタン・フェーズ行・撃破スコア横のアイコンが **絵文字でもリガチャ名でもなく**、アイコンとして表示される
- [ ] キャッシュ無効のハードリロード後も同様（古い `game.js` が残っていないこと）
- [ ] 開発者ツールの Network で `materialicons`（woff2）が **失敗していない**こと（オフライン時は表示が劣化し得るがクラッシュしない）
